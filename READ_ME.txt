-------------------------TRUE DETECTOR WEB EXTENSION PROJECT ----------------------------------------

Project True Detector — Project Summary
Project True Detector is a browser-based security extension designed to scan webpages and identify potentially suspicious, fraudulent, or malicious content. Its goal is to help users browse the internet more safely by combining automated scanning, security rules, and AI-assisted analysis.


1. Project Overview
- Project name: True Detector
- Project type: Chrome browser extension
- Primary purpose: Webpage threat detection and suspicious-content analysis
- Platform: Google Chrome
- Core technologies: JavaScript, HTML, CSS, Chrome Extension APIs, and AI integration
- Target users: Everyday internet users, students, and people concerned about online scams and phishing.


2. Main Features
- Webpage scanning: Examines webpage text and other eligible content for suspicious indicators.
- Phishing detection: Uses security rules to identify patterns commonly associated with phishing and fraudulent pages.
- AI-assisted analysis: Supports AI-based analysis through a configurable Gemini API integration.
- Image scanning: Checks eligible webpage images for suspicious content where supported by the scanning pipeline.
- Animated scanning interface: Displays a moving scan line and progress indicator during manual scans.
- Real-time scan feedback: Reports scanning progress and findings as processing continues.
- Extension popup: Provides a convenient interface for initiating scans and viewing results.
- Configurable settings: Allows users to configure the API key and related options.
